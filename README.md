# Система поиска и сравнения рентгеновских снимков (OPTG)

Веб-приложение для поиска и сравнения ортопантомограмм (ОПТГ) с использованием нейронных сетей. Система позволяет загружать рентгеновские снимки, сравнивать их между собой и искать похожие изображения в базе данных.

## Возможности

- **Сравнение изображений**: Загрузка двух рентгеновских снимков и вычисление степени их схожести
- **Векторный поиск**: Поиск похожих снимков в PostgreSQL через FAISS-индекс (косинусная близость эмбеддингов, top-5)
- **Извлечение признаков**: Автоматическое извлечение признаков из изображений с помощью нейронной сети
- **Многоязычные шаблоны**: Шаблоны интерфейса на русском и английском языках (на текущий момент маршруты отдают русские версии)
- **Асинхронный backend**: Асинхронные эндпоинты FastAPI и асинхронное подключение к БД (SQLAlchemy + asyncpg)

## Технологии

- **Backend**: FastAPI (Python 3.13)
- **Нейронная сеть**: ConvNeXt Tiny (через библиотеку timm), PyTorch
- **Поиск по схожести**: FAISS (faiss-cpu)
- **База данных**: PostgreSQL с асинхронным доступом (SQLAlchemy + asyncpg)
- **Обработка изображений**: OpenCV, Albumentations
- **Frontend**: HTML/CSS/JavaScript с шаблонами Jinja2

## Установка

### Предварительные требования

- Python 3.13 или выше
- PostgreSQL база данных
- CUDA-совместимая видеокарта (опционально, для ускорения на GPU)

### Шаги установки

1. **Клонирование репозитория**

   ```bash
   git clone <repository-url>
   cd Master_thesis
   ```

2. **Создание виртуального окружения**

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/Mac:
   source .venv/bin/activate
   ```

3. **Установка зависимостей**

   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка базы данных**

   Создайте базу данных PostgreSQL.

   Настройте файл `backend/config.env` для параметров приложения:

   ```env
   HOST=127.0.0.1
   PORT=8000
   ```

   Создайте файл `backend/Databases/db_config.env` с настройками подключения к БД:

   ```env
   SQLALCHEMY_DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/database_name
   ```

   Файл `db_config.env` используется скриптом `Database.py` для подключения к базе данных.

5. **Создание таблиц в базе данных**

   Автоматическое создание таблиц в коде не предусмотрено — создайте их вручную. Минимальная схема:

   ```sql
   CREATE TABLE images (
       id SERIAL PRIMARY KEY,
       patient_id VARCHAR(50) NOT NULL,
       filename VARCHAR(255) NOT NULL,
       storage_path TEXT NOT NULL,
       upload_date TIMESTAMP DEFAULT NOW(),
       age INTEGER,
       sex VARCHAR(1),
       metadata JSON
   );
   ```

6. **Заполнение базы данных**

   Скрипт `backend/Databases/insert_in_db.py` импортирует записи из CSV-файла со столбцами `id`, `age`, `sex`, `path_to_img`:

   ```bash
   cd backend/Databases
   python insert_in_db.py
   ```

   > **Примечание:** путь к CSV-файлу задан в переменной `CSV_FILE_PATH` внутри скрипта — измените его перед запуском.

7. **Подготовка модели нейронной сети**

   Поместите обученную модель в папку `backend/NNModels/PretrainedModels/` с именем `final_model.pth`.
   Модель должна быть обучена с использованием архитектуры ConvNeXt Tiny.

   При наличии файла шаблона `smiMIM_backbone_convnext_tiny_batch_24_final_correct.pth` (в каталоге `ForNNTrain/backbones/`) он будет использован для инициализации backbone; если файла нет, используются веса ImageNet.

8. **Построение векторного индекса FAISS**

   Поиск по базе данных работает через FAISS-индекс. Постройте его после заполнения БД:

   ```bash
   cd backend
   python VectorIndex/build_index.py
   ```

   Скрипт извлечёт эмбеддинги всех изображений из БД и сохранит индекс в `backend/VectorIndex/` (`faiss_index.bin` + `id_mapping.json`). Без построенного индекса эндпоинт `/search/` возвращает ошибку 503.

## Использование

### Запуск приложения

```bash
cd backend
python main.py
```

Приложение будет доступно по адресу: http://127.0.0.1:8000

### Основные страницы

- **Главная страница** (`/`): Информация о системе
- **Загрузка** (`/upload/`): Редирект на страницу сравнения
- **Сравнение** (`/compare/`): Загрузка изображений для сравнения или поиска
- **Результаты** (`/result/`): Редирект на страницу сравнения
- **Документация API** (`/docs`): Интерактивная документация FastAPI (Swagger UI)

### API эндпоинты

Эндпоинты возвращают HTML-страницу результата (шаблон `resultRU.html`), а не JSON.

#### POST `/search/`

Поиск 5 наиболее похожих изображений в базе данных через FAISS (косинусная близость эмбеддингов).

**Параметры:**

- `user_image` (UploadFile): Изображение для поиска

**Поддерживаемые форматы:** `.png`, `.jpg`, `.jpeg`

**Ответ:** HTML-страница со списком найденных совпадений (ранг, имя файла, схожесть в %) и лучшим совпадением.

**Ошибки:**

- `400` — файл не загружен или неподдерживаемый формат
- `503` — векторный индекс FAISS не построен

#### POST `/compare/`

Сравнение двух загруженных изображений моделью `SiameseMetricModel`.

**Параметры:**

- `user_image` (UploadFile): Первое изображение
- `user_image1` (UploadFile): Второе изображение

**Поддерживаемые форматы:** `.png`, `.jpg`, `.jpeg`

**Ответ:** HTML-страница с вердиктом — «Один человек» или «Разные люди». Порог принятия решения: `0.95` (переменная `COMPARE_THRESHOLD` в `DatabaseRouter.py`).

### Пример использования

1. Перейдите на страницу "Загрузка"
2. Выберите режим: "Сравнение" или "Поиск в базе"
3. Загрузите одно или два изображения
4. Нажмите "Анализировать"
5. Просмотрите результаты со степенью схожести (в процентах)

## Архитектура нейронной сети

Система использует модель **SiameseMetricModel** на базе архитектуры **ConvNeXt Tiny**:

- Backbone: ConvNeXt Tiny (предобученный на ImageNet или инициализированный из файла backbone)
- Пулинг: комбинация GeM, Attention Pooling, Average Pooling и Max Pooling
- Embedding head: Linear → BatchNorm → ReLU → Dropout → Linear, выход — L2-нормированный 512-мерный эмбеддинг одного изображения
- Classifier head (для пар): на вход `[emb1, emb2, |emb1 − emb2|]` → Linear(1536→256) → ReLU → Dropout → Linear(256→1) → sigmoid
- Сравнение: вероятность ≥ 0.95 — «Один человек», иначе — «Разные люди»
- Поиск: эмбеддинги изображений БД индексируются FAISS (`IndexFlatIP`, косинусная близость на L2-нормированных векторах)

## Утилиты

### Создание датасета (`utils/create_dataset.py`)

Скрипт для формирования CSV-файла `metadata_dataset.csv` (столбцы `id`, `age`, `sex`, `path_to_img`) из папок с изображениями. Перед запуском укажите пути к папкам с данными в начале скрипта.

### Копирование изображений (`utils/concat_images.py`)

Копирует все изображения из датасета в единый каталог `./dataset/images/` с именами `{id}.jpg`.

### Матрица ошибок (`utils/confusion_matrix.py`)

Визуализация матрицы ошибок классификации (seaborn heatmap).

### Визуализация аугментаций (`utils/drawImagefortrain.py`)

Отображает изображение до и после применения трансформаций для обучения. Импортирует `get_train_transforms` из каталога `ForNNTrain/` (не входит в репозиторий).
